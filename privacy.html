Xflomo

隐私政策

生效及最后更新日期：2026 年 10 月 30 日

Xflomo 是为 X.com 提供界面样式、发帖活动展示、关注账号快捷入口和聊天布局优化的浏览器扩展。本政策说明扩展如何处理信息，以及您如何管理本地数据。

开发者：@Magellan.Zh麦哲张。Xflomo 是独立开发的第三方扩展，与 X 或 flomo 无官方关联。

1. 扩展读取和保存的信息

  • 界面设置：样式开关、广告隐藏截止时间等偏好。
  • 账号资料：X 页面提供的昵称、用户名、头像链接，以及帖子数、关注数和粉丝数。
  • 发帖活动：本人帖子标识和发布时间，用于生成发帖活动热力图；不建立帖子正文数据库。
  • 关注列表：关注账号的用户名、昵称、头像及本地头像缓存，用于快捷入口和减少重复加载。

扩展会读取 X 页面及相关页面请求响应中的上述信息，也可能临时打开本人资料或关注列表页面进行读取，完成后关闭。账号资料、发帖统计、关注列表与设置保存在您当前 Chrome 配置的 chrome.storage.local 中，不由扩展上传到开发者服务器。

2. 信息的使用目的

这些信息仅用于提供扩展已描述的界面和导航功能、展示本人发帖活动、缓存头像、保留用户偏好及控制推广位的隐藏状态。扩展不出售用户数据，不使用账号资料、发帖活动或关注列表进行个性化广告投放，也不将这些信息用于信用评估或贷款。

3. 网络请求和第三方服务

  • X.com：利用当前已登录的 X 页面读取功能所需的资料。X 自身的登录和服务请求由 X 按其政策处理。
  • pbs.twimg.com：请求账号头像图片，并可将图片缓存在本地。
  • aiheadshotnow.com：请求 https://aiheadshotnow.com/api/xflomo/ad，获取是否展示推广位、推广文案和目标链接等 JSON 数据。扩展不会在该请求中附带账号资料、关注列表、发帖记录或持久安装标识，且请求设置为不携带凭据、不发送来源页信息。

任何外部网络请求都需要将来源 IP 地址等连接信息提供给对应服务。服务提供方及其托管、CDN 或安全服务可能接收或记录 IP 地址、请求时间、请求路径和技术请求头。这类服务器日志是否保存及保存期限取决于对应服务的实际配置；本扩展不承诺第三方不记录此类信息。

点击推广链接后会打开目标网站；该网站的数据处理由其自身隐私政策决定。此页面本身不加载分析脚本、广告脚本或第三方字体，但 GitHub Pages 的托管服务可能处理访问请求信息，详见 GitHub 隐私声明。

4. 广告与控制方式

页面可能展示明确标注为“推广”的广告。您可通过推广位的关闭按钮将其隐藏 72 小时；隐藏期间，包括刷新页面时，扩展不会请求广告配置。隐藏期满后可重新获取并展示广告；如果页面持续打开，现有到期计时器也可能触发恢复请求。扩展没有每 5 分钟自动刷新广告的周期任务。

5. 不主动收集的信息

扩展不主动读取或保存密码、认证 Cookie、登录令牌、支付信息、健康信息、设备定位、私人聊天内容，也不记录浏览历史、键盘输入、鼠标轨迹或点击行为日志。聊天功能用于调整页面布局，不采集私信内容。扩展未集成用户行为分析或第三方广告追踪 SDK。

6. 数据保存和删除

本地缓存可跨浏览器会话保留，部分数据会在后续使用时更新；关闭界面样式不等于删除已保存的数据。您可以通过 Chrome 的扩展管理功能卸载 Xflomo，以移除该扩展的本地存储；高级用户也可通过扩展开发者工具清除 chrome.storage.local。重新安装后，扩展可能再次读取所需信息。

本地数据清除不会删除您在 X 账户中的资料或内容，也不会删除外部服务已产生的访问日志；外部服务数据需通过其自身渠道管理。

7. 安全与有限使用

扩展将相关本地数据限制在 Chrome 扩展存储中，并通过 HTTPS 请求上述服务。我们不将本地存储描述为端到端加密，设备及浏览器配置的安全仍由您管理。

Xflomo 对用户数据的使用和转移遵守 Chrome Web Store User Data Policy，包括其中的 Limited Use（有限使用）要求。用户数据仅用于实现已披露的功能，不用于无关目的，也不用于个性化、再营销或基于兴趣的广告。

8. 政策变更与联系

当扩展功能或数据处理方式发生变化时，本政策会相应更新，并调整页面顶部的日期。若您对隐私或数据删除有疑问，可通过 GitHub Issues 或 开发者 X 主页 联系。请勿在公开 Issue 中发布密码、私信或其他敏感资料。
